# Greece Chauffeur Service — Operations & Dispatch System

Executive black-car and chauffeur transport management system for Greece. Built with Next.js 16 (App Router), Cloudflare Workers, and Cloudflare D1 (SQLite).

## Features & Architecture

- **Runtime:** Cloudflare Workers via `@opennextjs/cloudflare`
- **Database:** Cloudflare D1 (SQLite) with relational schema for bookings, quotes, customers, chauffeurs, vehicles, payments, invoices, and audit logging
- **Authentication:** Web Crypto API password hashing + cookie-based D1 session management with role-based access control
- **Admin Shell:** Executive dark theme with responsive sidebar navigation, operational dashboard, and quick action workflows
- **Styling:** Custom CSS design system (zero runtime, no Tailwind dependency)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Database Migration

Apply the database schema to your Cloudflare D1 database:

```bash
# Local development D1
npx wrangler d1 execute greece-chauffer-transfers-db --local --file=schema.sql

# Production Cloudflare D1
npx wrangler d1 execute greece-chauffer-transfers-db --remote --file=schema.sql
```

### 3. Seed Super Admin User

Run the seed script or execute the generated query:

```bash
npx tsx lib/seed.ts
```

Default credentials generated by seed:
- **Email:** `admin@greecechauffeur.com`
- **Password:** `Admin@123456` (change after first sign-in)

### 4. Run Locally

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) or [http://localhost:3000/login](http://localhost:3000/login).

## Deployment

```bash
npm run pages:build    # Build for Cloudflare
npm run pages:deploy   # Build & deploy to Cloudflare Workers
```
